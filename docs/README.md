# Penciltrade user guides

These eight guides explain trading, orders, balances, PENCIL, prices, permissions, and recovery on Solana mainnet.
The program source defines the contract behavior. The guides explain how that behavior affects your funds and actions.
The guides use the repository's [AGPL-3.0-only license](../LICENSE).
